## Güncelleme paketleri

Riftroam'un imzalı Windows güncelleme paketleri burada yayınlanır.

Bu repo **kaynak kod deposu değildir**. Release varlıkları NSIS kurucusu, Tauri `.sig` imzası, `latest.json` ve `SHA256SUMS.txt` ile sınırlıdır. Riftroam istemcisi yalnız gömülü açık anahtarla doğrulanan paketleri kurar.

Güncelleme manifesti:

`https://github.com/yuefdev/riftroam-releases/releases/latest/download/latest.json`

## English

[Riftroam](https://riftroam.com/en/) is a free Windows companion for League of Legends. It brings LoL custom skins, 3D skin preview, Ultra skins with forms, match analysis, tier lists and a live game view together in one app.

- [Home and features](https://riftroam.com/en/)
- [Download and installation](https://riftroam.com/en/download/)
- [LoL custom skin guide](https://riftroam.com/en/custom-skin/)
- [Skin changer comparison](https://riftroam.com/en/skin-changer/)
- [Troubleshooting](https://riftroam.com/en/troubleshooting/)
- [Patch notes](https://riftroam.com/en/changelog/)

This is not a source repository. It only hosts the signed Windows update packages: the NSIS installer, the Tauri `.sig` signature, `latest.json` and `SHA256SUMS.txt`. The Riftroam client installs only packages that verify against its embedded public key.
